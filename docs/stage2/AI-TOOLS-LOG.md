### Counting Gemini tokens

Every LLM call is logged in `trace.jsonl` as `tokens IN/OUT`. To total them, run this in the repo folder:

```bash
grep -o 'tokens [0-9]*/[0-9]*' trace.jsonl | awk -F'[ /]' '{i+=$2; o+=$3} END {print i" input, "o" output tokens, "NR" calls"}'
```

The Google AI Studio usage page (aistudio.google.com → Usage) shows the same numbers per day.
